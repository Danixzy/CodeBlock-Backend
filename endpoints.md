## 📚 Endpoints da API

### Usuários

- `POST /api/users/register` - Registrar novo usuário
- `POST /api/users/login` - Login
- `GET /api/users` - Listar usuários (autenticado)
- `GET /api/users/:id` - Buscar usuário (autenticado)
- `PUT /api/users/:id` - Atualizar usuário (autenticado)
- `DELETE /api/users/:id` - Deletar usuário (autenticado)

### Produtos

- `POST /api/products` - Criar produto (autenticado)
- `GET /api/products` - Listar produtos (autenticado)
- `GET /api/products/:id` - Buscar produto (autenticado)
- `PUT /api/products/:id` - Atualizar produto (autenticado)
- `DELETE /api/products/:id` - Deletar produto (autenticado)
